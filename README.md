# Kevin Grainger: projects

I'm a quantitative analyst in London, working on climate physical risk. These are my side projects, in earth systems, signal processing and energy and commodity markets. Some grew out of my current role, and many began as numerical simulations in my theoretical physics degree. Most take a published model and change it, or apply it to a particular case.

The numbers follow the order on the website. The folder names keep the numbers each project was started under.

**Running it.** Each folder has its notebooks with outputs saved. `pip install -r requirements.txt` covers every project except two: the copper project's smelter time series also needs `earthengine-api`, and the Spanish solar dataset pipeline has its own environment (`008-spanish-solar-portfolio/iberia_datasets/requirements.txt`) and runs in Docker. CI runs the `corrlib` tests, the Po Valley solver tests and the dataset-pipeline tests on every push.

**Figures** live in each project's `figures/` folder: a `cover` image (made by `make_covers.py`, about 2,600 px wide) plus numbered figures in PNG and PDF, all in one shared style (`figstyle.py`). Figures made from simulated data carry a small footnote saying so.

**Data:** small open datasets are committed next to the code. Market prices that can't be redistributed are re-downloaded by each project's scripts, and the large ERA5 dataset for the Spanish solar project is attached to a GitHub Release. [`DATA.md`](DATA.md) lists every dataset, where it lives and how to get it. Open work is listed in [`NEXT_STEPS.md`](NEXT_STEPS.md).
